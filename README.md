# Subham Karmakar — Portfolio

Personal developer portfolio for **Subham Karmakar** (.NET Full-Stack Developer), built with static HTML, CSS, vanilla JavaScript, and self-hosted PDF.js for cross-device inline CV rendering (Desktop, Android, and iOS).

## Features
- Light & Dark theme toggle with circular View Transitions wipe and `theme-color` sync
- Bento hero overview, live India (`IST`) clock, and tech stack marquee
- Sticky-stacking project showcase cards (`CityHangAround`, `Issue-Tracker`, `Myra`, `Advanced PHP Online Quiz App`, `Terminal 1`)
- Inline CV viewer powered by bundled PDF.js (`assets/vendor/pdfjs/`) + direct download
- Responsive mobile drawer and day/night animated Cooch Behar skyline footer

## Deployment
Static site ready for zero-config deployment on **Vercel** (`vercel.json` included) or **GitHub Pages**.
